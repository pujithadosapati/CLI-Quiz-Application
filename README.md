# CLI Quiz Application Using Python
## Project Description
The CLI Quiz Application is a command-line-based quiz program developed using Python. It displays multiple-choice questions, accepts user answers, checks the answers, calculates scores, and displays the final result.
## Objectives
- Practice Python programming.
- Understand lists and dictionaries.
- Learn JSON data handling.
- Implement loops and functions.
- Calculate quiz scores.
## Technologies Used
- Python
- JSON
- Random Module
- Programiz Online Compiler
## Features
1. Contains 10 multiple-choice questions.
2. Accepts answers from users.
3. Checks correct and incorrect answers.
4. Randomizes question order.
5. Handles invalid inputs.
6. Calculates final score and percentage.
7. Displays performance summary.
## How to Run
1. Open Programiz Online Python Compiler.
2. Copy the Python source code.
3. Paste it into the editor.
4. Click the Run button.
5. Enter your name.
6. Answer all questions using A, B, C or D.
7. View your final score.
## Concepts Learned
- Python Lists
- Dictionaries
- Functions
- For and While Loops
- Conditional Statements
- JSON Parsing
- Random Module
- User Input Validation
## Expected Result
The application displays the total questions, correct answers, wrong answers, final score, percentage and performance.
